## 真实协议与原生边界

T08 实际通过 CDP transport 执行 `DOM.getDocument`、`DOM.querySelector`、`DOM.getAttributes`，取得当前商品节点与属性；导航后旧节点返回 `Could not find node with given id`。这是实际 CDP 证据，**不是 Protocol monitor 面板点击录像**。

T06 自动测试使用临时生成的真实 EC P-256 密钥构造 none attestation / ES256 断言，执行注册解析、签名校验与一次性挑战；错误 origin、challenge、RP、UP / UV、凭据、签名、回退计数和非法 CBOR 拒绝。这里不是浏览器虚拟认证器录制。IAB 的 raw CDP 不支持 WebAuthn.enable，因此没有伪造真实 create/get 通过。真实入口和服务器已实现，以下原生步骤仍待人工复核。
