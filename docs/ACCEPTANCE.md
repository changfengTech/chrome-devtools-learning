# 验收标准

## 完整交付

| 维度 | 标准 |
| --- | --- |
| 范围 | 55 主线、8 专题、8 章末挑战；八大面板及约定辅助工具有真实任务 |
| 教学 | 目标、原理、交互、实战、迁移题、三级提示、答案、复盘齐全 |
| 准确 | 英文名称对应实际工具；官方来源与实测版本可追溯；判断说明边界 |
| 真实 | 故障可在 DevTools 观察；修复改变实际行为；教学模型和实测明确区分 |
| 重复 | 重置后核心实验连续 3 次复现和修复；波动实验按趋势及正常对照判定 |
| 挑战 | 改变条件，要求证据和验证；不能只点击完成 |
| 诚实 | 自动检查说明检查依据；不假装读取用户的 DevTools 点击或人工文字判断 |
| 体验 | 按需提示、跳课、重试、复习；键盘可用，焦点可见，减弱动态，窄窗口适配 |
| 本地 | 按说明启动，核心实验不依赖外部业务接口；记录持久化且可导入导出 |
| 工程 | 类型和构建通过；接口、记录校验、实验隔离与挑战判定有针对性验证 |

## 评分与记录

五项各 0–2 分：复现准确、工具选择、证据有效、根因解释、修复验证。0=缺失/错误，1=部分成立，2=有正确且充分的依据。章末及综合题目标至少 8/10，证据和验证均不得 0 分。使用提示单独记录，不锁后续课程。

已阅读：用户主动记录读完。已练习：目标实验运行且完成证据检查。挑战通过：迁移题达到明确规则。自由笔记保留为自查，不以关键词匹配冒充理解评分。

第 21 课是范围更窄的自动检查：本地服务验证挑战实验运行、故障/修复对照运行及诊断选择，浏览器测量用于反馈；不能宣称这已经完成五维人工评分或章末能力认证。

第 01–18 课同样采用范围有限的自动检查：实验页运行故障、检查实际 DOM/值/请求次数并报告；服务核对已完成的会话请求、报告结构、原因、证据与验证选项。五项全部通过才保存练习/挑战状态。报告由本地浏览器发送，不是可信监考，不证明用户实际设置过某类断点。查看解析单独记录，错误提交不直接显示正确答案。逐课规则见 [实验合同](FOUNDATIONS-01-18.md)。

## 第 01–18 课本批验收

- 18 个不同的可操作原理模型；每课分别提供引导商城和改变数据/故障配置的挑战。
- 每课两种故障均有真实可观察结果；正确对照改变实际行为，错误对照不通过。
- 全部引导故障与修复在浏览器中连续运行三轮；挑战两种配置都有浏览器通过记录。
- Sources 提供实际编译 JS、原始 TS、有效 Source Map；可暂停业务并检查调用栈和单步位置。
- 笔记、阅读、练习、挑战及辅助标志持久化；旧记录保持兼容；非法导入不覆盖。
- 320/768/1440 下 18 课模型页无整页横向溢出；商城窄屏修复对照可用。
- 对应脚本、判定边界、来源与实测结果可追溯。[验收记录](QA-FOUNDATIONS.md) 区分实际通过和仍待独立 Chrome 人工复核的项目。

## 八个面板章末题

| 面板 | 新故障任务 | 必需证据 |
| --- | --- | --- |
| Elements | 新商品卡片样式、布局或点击异常 | 节点、生效规则/布局关系、前后对比 |
| Console | 新优惠计算异常 | 关键错误/值、验证表达式、依据 |
| Sources | 特定商品错误合计 | 断点、变量/调用关系、首次偏离位置 |
| Network | 列表失败、延迟或旧数据之一 | 请求、详情/时序、下一步验证 |
| Performance | 新交互卡顿 | 有效选区、耗时活动、统一条件复测 |
| Application | 刷新/重开/离线后状态异常 | 存储层、控制/读取关系、恢复验证 |
| Memory | 重复操作持续保留 | 步骤、对比、保留引用、修复趋势 |
| Lighthouse | 新配置质量检查 | 环境、发现、手工验证、优先级、复测 |

## 自动化验证重点

- 实际等待主要发生在响应头之前；传输场景在响应开始后持续发送主体。
- 修复改变对应服务行为；未知场景、过期挑战、缺失对照不能通过判定。
- 学习记录损坏、版本错误或非法课程 ID 不得破坏页面；导入失败不得覆盖旧记录。
- 商城与教程不同源，实验不包含 Vue 热更新和调试插件。

## Network / Application 本批标准

- 19、20、22–26、35–39 共 12 个新模型；每课引导在同一会话连续三轮复现/修复，独立挑战两种配置均浏览器通过；21 的等待与传输完整回归。
- 核对真实协议与状态：HTTP 422/200 业务错误、瀑布请求依赖、HTTP 缓存与条件 304、CORS OPTIONS/POST、503 重试及 404、SSE / WebSocket、Cookie 请求头、真实 Storage / IDB 事务及 worker 控制和 Cache Storage。
- 区分 HTTP 缓存、内存状态和 Cache Storage；离线验证必须证实 worker fetch 失败。只对页面设置 CDP Offline 不足以证明 worker 离线。
- worker scope、Cookie、数据库、缓存、键按会话隔离；清理只处理当前会话，过期会话也能打开清理入口。
- 两个章末初始隐藏课号和步骤；案例自动检查及五维人工自评分别呈现。低分不记录完成，自评不作为自动能力认证。
- 13 课及两个章末页面在 320/768/1440 检查，45 项主文档无横向溢出；记录导入导出保留章末字段并兼容旧 v1。
- 应用内 Chromium 的实测与独立 Chrome 英文面板的人工复核分别记录；具体版本不可得时不推断。证据见 [本批验收](QA-NETWORK-APPLICATION.md)。
