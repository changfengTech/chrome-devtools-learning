# 04 · 从页面定位 DOM

由 `pnpm docs:lessons` 生成。脚本数据：`src/data/foundations.json`；实验合同补充：`scripts/generate-foundations.mjs`。本页含教师参考答案，独立挑战前可先不阅读。

## 学习目标与先修

建立视觉与 DOM 对应关系，会搜索和编辑节点。前置：已完成前 3 课或掌握等效基础。

## 原理与交互演示

页面外观和 DOM 层级不是一回事。优先找承载目标文本的精确节点，避免误改整个容器。

页面演示：页面与节点树双向定位。这是可重置的教学模型，演示本身不写入实战完成记录。

1. 点击页面与节点树双向定位。
2. 修改文本节点。
3. 检查容器和子节点的区别。

操作时先预测结果，再改变一个条件，比较输出；可用「重置演示」恢复初始模型。

### DOM 是当前页面的对象树

浏览器把 HTML 解析成节点树，JavaScript 可以继续增删和改写。Elements 显示当前 DOM；View Source 显示最初源码，两者可能不同。

### 选对节点再修改

点击 Inspect 再选价格，确认高亮只覆盖目标；父节点可能包含货币符号、数字和其他内容。用 data-sku 或 id 找到目标，再核对 textContent 与接口数据。

### 临时改动用于验证

在 Elements 编辑文字会直接改变这次页面，可以验证显示位置。它不会自动修复生成错误值的 JavaScript；恢复故障或刷新会重新渲染。

## 商城实战与实验合同

症状：价格数字或商品名称被写进了错误的嵌套节点。

正常结果：价格和标题分别与 data 响应中的 price、name 一致。

实现与可观察对象：Inspect、Ctrl/Cmd+F 搜索 data-sku，修改对应文本，不删除相邻商品。

1. 从本课准备并打开独立商城；先打开 DevTools，再点「运行故障」。
2. 使用 Inspect 选商品价格，展开到 #price-value；Ctrl/Cmd+F 搜索本次 data-sku。
3. Network 的 data Response 中核对 price 和 name；区分价格数字节点与标题节点。
4. 在 Elements 双击目标文本，只改回实际数据；保持货币符号和相邻商品，再点「检查当前页面」。
5. 保持其他条件不变，手工验证或选择针对本故障的对照方案。
6. 核对正常结果与故障差异，回教程选择直接证据并记录练习。

固定数据：单价 34、数量 2、优惠 7，适用计算课的正常总额 61。第 03 课配置二故意改变数量；随机题使用本会话实际数据。

## 独立挑战与答案

定位嵌套节点引起的显示异常。挑战变更输入与故障配置，不能仅凭引导案例的位置或数值选择。先复现并修复，再回教程选择原因、证据和验证。

| 配置 | 原因 | 可核对证据 | 参考修复/验证 |
| --- | --- | --- | --- |
| 配置1 | 价格数字节点被错误更新 | price-value 的 textContent 与订单数据不一致 | 只修正价格数字节点 |
| 配置2 | 商品标题节点被错误更新 | product-title 的 textContent 与订单数据不一致 | 只修正商品标题节点 |

## 三级提示

1. 先稳定复现，找第一次偏离预期的结果；不要同时改变多个条件。
2. Inspect 商品卡片，搜索 data-sku；展开 #price-value 和 #product-title，修改目标文本后点击「检查当前页面」。
3. 比较真实值、规则或调用位置与预期。引导案例使用第一种故障，迁移案例会更换数据和故障配置。

## 误区、重置与复盘

编辑 DOM 是临时实验；刷新或恢复会重新渲染，不会修改业务源文件。

点商城「恢复故障」可重新渲染初始案例；重新准备会话会清空当前观察与选择，不删除已保存学习记录。会话 30 分钟失效，服务重启后重新准备。修复完成后清除本课断点、恢复 caught 异常开关及网络条件；刷新清除临时 DOM/CSS 修改。

复盘记录：症状、实际证据、首次偏离位置、最小改动、复测结果，以及尚不能确定的范围。
