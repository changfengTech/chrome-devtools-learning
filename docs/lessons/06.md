# 06 · 看懂布局

由 `pnpm docs:lessons` 生成。脚本数据：`src/data/foundations.json`；实验合同补充：`scripts/generate-foundations.mjs`。本页含教师参考答案，独立挑战前可先不阅读。

## 学习目标与先修

掌握盒模型、Flex/Grid 和溢出定位。前置：已完成前 5 课或掌握等效基础。

## 原理与交互演示

先观察盒模型与布局约束，再用 Flex/Grid overlay 检查空间分配。修复后要验证相邻内容。

页面演示：调整尺寸与约束，观察布局变化。这是可重置的教学模型，演示本身不写入实战完成记录。

1. 改变最小宽度。
2. 改变列间距。
3. 调整容器宽度。

操作时先预测结果，再改变一个条件，比较输出；可用「重置演示」恢复初始模型。

### 布局约束共同决定空间

网格容器宽度、列定义、子项最小宽度、padding 和 gap 都占用空间。两列并不保证每列内容都能缩进可用宽度，min-width 可能把子项撑开。

### overlay 与尺寸互相印证

Grid overlay 显示轨道和间距；盒模型显示 padding、border 和尺寸。scrollWidth 大于 clientWidth 表示存在横向内容，继续看是哪一项或间距超出。

### 修约束，再换窗口复测

子项改 min-width:0 或恢复合理 gap 后，以同样宽度比较。再缩窄窗口，确认内容仍可读。仅隐藏 overflow 可能只是把错误内容裁掉。

## 商城实战与实验合同

症状：窄商品容器出现横向溢出。

正常结果：网格 scrollWidth ≤ clientWidth + 1，商品内容保持可读。

实现与可观察对象：固定最大宽度 360px 的真实网格；250px 子项最小宽度或 480px 列间距造成溢出。

1. 从本课准备并打开独立商城；先打开 DevTools，再点「运行故障」。
2. Elements 选择 #product-grid，点 grid 徽章或 Layout 中的 Grid overlay；查看轨道与间距。
3. 选中子项查看盒模型、min-width；再检查网格 gap。可在 Console 对 $0 比较 scrollWidth 与 clientWidth。
4. 只将子项 min-width 改为 0 或把 gap 恢复 12px；换窄窗口确认内容可读后点「检查当前页面」。
5. 保持其他条件不变，手工验证或选择针对本故障的对照方案。
6. 核对正常结果与故障差异，回教程选择直接证据并记录练习。

固定数据：单价 34、数量 2、优惠 7，适用计算课的正常总额 61。第 03 课配置二故意改变数量；随机题使用本会话实际数据。

在新视口定位溢出并验证相邻内容。挑战变更输入与故障配置，不能仅凭引导案例的位置或数值选择。先复现并修复，再回教程选择原因、证据和验证。

| 配置 | 原因 | 可核对证据 | 参考修复/验证 |
| --- | --- | --- | --- |
| 配置1 | 子项 min-width 撑开网格 | 子项最小宽度大于可用列宽 | 将子项 min-width 改为 0 |

## 三级提示

1. 先稳定复现，找第一次偏离预期的结果；不要同时改变多个条件。
2. Elements 选择 #product-grid，开启 Grid overlay；比较 scrollWidth、clientWidth 与子项 min-width / column-gap。
3. 比较真实值、规则或调用位置与预期。引导案例使用第一种故障，迁移案例会更换数据和故障配置。

## 误区、重置与复盘

Grid overlay 是辅助观察；修改 grid 后还要查看 min-width 与 gap。仅缩小字号不解决原因。

点商城「恢复故障」可重新渲染初始案例；重新准备会话会清空当前观察与选择，不删除已保存学习记录。会话 30 分钟失效，服务重启后重新准备。修复完成后清除本课断点、恢复 caught 异常开关及网络条件；刷新清除临时 DOM/CSS 修改。
