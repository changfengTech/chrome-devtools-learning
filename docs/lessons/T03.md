# T03 · Workspaces 与映射排错

由 pnpm docs:lessons 生成；内容源 src/data/advanced.json，合同源 scripts/generate-advanced.mjs。含教师参考答案。前置：13、52。

## 目标与原理

关联本地文件并诊断异常 Source Maps。Source Maps 连接产物和源码；Workspaces 连接网络资源和本地文件，保存与构建仍是不同步骤。

### 映射链

脚本 sourceMappingURL → map → sources / sourcesContent；先确认下载与版本。

### 磁盘保存

只授权本课下载的练习目录，保存后在磁盘读取确认，再构建或刷新。

### 失败证据

404 与旧 sourcesContent 的排查路径不同；不能只看漂亮的 TS 文件名。

## 交互演示

打断映射观察断点和修改。改变本课输入条件并预测结果；对照请求、状态或约束的关系；切换最小修复并复位，核对改变的范围。综合题先提交判断再解锁因果模型，所有模型不计完成。

## 商城实战

断点跳到错误行，或者 Sources 中修改后磁盘文件没有变化。

1. 执行计算并打开实际 cart.js，记录 sourceMappingURL 与结果。
2. Sources / Developer Resources 核对 map 下载状态、sources 与 sourcesContent。
3. 下载本课 cart.ts，保存到独立练习目录；Workspaces Add folder manually 只授权该目录。
4. 对照网络源码建立映射，保存一个注释，回磁盘确认实际落盘位置。
5. 应用映射对照后重新加载脚本，在乘法位置断点核对 Scope 和结果。
6. 移除 Workspace 连接并恢复文件；页面映射检查不证明目录授权和保存已经执行。

## 独立挑战与参考答案

修复映射并验证实际保存位置。新输入与两种故障随机；可能再次抽到同种，不保证轮流。

| 配置 | 根因 | 实际证据 | 针对性验证 |
| --- | --- | --- | --- |
| 配置1 | sourceMappingURL 指向不存在的 map | Developer Resources / Network 中映射地址返回 404 | 修正映射 URL，清除错误条件并核对断点行 |
| 配置2 | map 的 sourcesContent 来自旧版本源码 | 已加载 map 内容仍是加法版本，与实际乘法结果不一致 | 同步当前源码与 map，确认磁盘文件和运行结果一致 |
| 干扰项 | 只根据表面现象修改无关条件 | 没有保留条件与输入的一次截图 | 同时改变设备、数据与逻辑，只保留成功结果 |

## 三级提示

1. 先复现 断点跳到错误行，或者 Sources 中修改后磁盘文件没有变化。
2. 对照实际证据：Developer Resources / Network 中映射地址返回 404；或 已加载 map 内容仍是加法版本，与实际乘法结果不一致
3. 一次只改变对应原因：修正映射 URL，清除错误条件并核对断点行；或 同步当前源码与 map，确认磁盘文件和运行结果一致

## 验收、边界与恢复

提供真实 JS/map/TS 和下载文件；原生 Workspace 保存仍需要人工核对。 保持输入、数量、环境一致；完成故障与正常对照，选择一致证据；三轮引导和两配置挑战分别取证，原生步骤与本地结果分列。停止后清理本会话资源，再恢复浏览器设置。
