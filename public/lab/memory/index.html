    恢复与测量边界

    故障与对照在同一文档内执行；应用对照先撤销本页旧资源，再做相同批次。停止只清理本会话对象、监听器、定时器与请求；离页也会清理。刷新建立新对象环境，不能与刷新前按同一对象身份作比较。

    内存最多 20 次开关 / 运行，资源有界。拍快照前排除 Console、$0、选中节点等调试器引用。请勿将对象日志保存成全局变量来验证释放。强制 GC 和 Memory / Recorder 操作请在 DevTools 完成。
